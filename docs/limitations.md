# 已知限制

- Design manifest 只检查确定性结构与可访问性规则，不替代多模态视觉审美评审。
- Motion 支持黑帧、静音、关键帧抽样和 SRT 时间轴检查，但不做声音艺术、逐帧观看或字幕画面排版判断。
- Research 只验证主张与来源引用结构，不联网证明来源内容真实性或权威性。
- 六维评分依赖足够的 Criterion 和专业证据；自动检查不会把技术通过冒充专业高分。
- 同一进程自动检查不能替代独立专业复核；S 仅允许满足 Signature 条件的合格独立人工终审。
- Code 命令具有允许列表、超时和日志上限，但不提供操作系统级 CPU/内存沙箱。
- 没有 FFprobe/FFmpeg 时相应媒体检查会降级并明确记录。
- npm 安装包由 CI 在 Node.js 20、22、24 上测试核心功能，并在独立干净项目中执行安装包冒烟测试。
