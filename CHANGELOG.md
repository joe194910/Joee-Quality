# Changelog

## 0.1.0 - 2026-10-21

- Initial P0 implementation: Agent Skill, CLI, evidence ledger, blockers, coverage, JSON/Markdown reports, file/code/motion evaluators, comparison, verification, and local memory.
- Added Criterion-level assessments and evidence-reference validation.
- Added configurable Code test commands without shell argument concatenation.
- Added Draft-07 JSON Schema generation for reports.
- Added YAML-backed six-dimension scoring, explicit criterion denominators, coverage gating, and blocker-first grade calculation.
- Added Code command allowlisting, execution timeouts, bounded log capture, and no-shell process execution.
- Added FFmpeg black/silence detection, real frame sampling, and SRT overlap/overflow validation.
- Added structured Design accessibility checks and Research claim/source traceability checks.
- Added Quality Memory export, permanent deletion, disable, and enable controls.
- Added validated migration of unversioned and 0.1.0 reports to report schema 1.0.0.
- Added validated professional-review imports, Quick/Standard/Signature gate behavior, and human-only S eligibility.
- Added verification classification for fixed, open, added, regressed, and unverifiable findings.
- Added a versioned standalone integration contract and `evaluate-contract` CLI workflow.
- Fixed bundled rubric resource discovery and verified installation from an npm tarball in a clean project.
- Added Node.js 20/22/24 CI, package verification, and direct dependency license notices.
