# Joee-Quality 核心原则

Joee-Quality — Excellence by Design. We don't just make it work. We make it worth experiencing.

1. Intent before execution：先理解目标。正例：以 Brief 验收；反例：只看文件格式。
2. Craft beyond function：可用只是底线。正例：功能通过后检查细节；反例：能打开即高分。
3. Purposeful creativity：创意服务表达。正例：选择与受众和信息一致；反例：堆效果。
4. Coherent experience：局部服从整体。正例：统一节奏与层级；反例：单点漂亮但破坏叙事。
5. Evidence over assertion：证据优于断言。正例：引用测试日志；反例：“应该没问题”。
6. Critique before approval：审查不是自夸。正例：主动找反例；反例：只列优点。
7. Improve the work, not the score：改作品而非刷分。正例：最小修复真实缺陷；反例：绕过规则。
8. Learn only what holds up：验证后才固化。正例：跨样本重复后标 verified；反例：一次偏好即普适规则。

Quality DNA = 核心标准 + 领域标准 + 项目验收条件。Evidence Ledger 记录来源、范围、时间、工具与可信度。Repair Contract 包括最小修改面、预期改善、回归风险和复验。Quality Memory 遵循观察→验证→弃用。
