# Joee-Quality

Joee-Quality is an evidence-first delivery evaluation CLI and Agent Skill. It records verifiable evidence, unknowns, hard blockers, repair tasks, and stable JSON/Markdown reports. It is not an industry certification and never treats deterministic checks as proof of professional aesthetics.

Requires Node.js >=20. Install with `npm install && npm run build && npm link`, then run `jqs --help`. All P0 checks are local and artifact content is handled as untrusted data.
